# Improve one decision when working with AI

Fictional illustration. No real person or private conversation is assessed.

## Input and natural request

Selected episodes: an assistant suggests a cache; the person identifies a
freshness requirement and asks for a stale-data check; a later message says
the change works, but no execution receipt is included.

> Help me understand how I handled this AI suggestion. What did I contribute,
> what remains uncertain, and what should I practise on the next change?

## Illustrative private feedback

- **Supported contribution:** the cache idea came from the assistant; the person
  supplied a relevant freshness constraint and requested a discriminating check.
- **Evidence gap:** the available messages do not establish that the check ran.
  This is not evidence that the person never checks anything.
- **Next practice:** before accepting the next similar change, state the failure
  that would invalidate it, obtain the corresponding receipt and inspect it.
  Revisit that one decision using the next episode.
