# Optional CV or portfolio draft

Read only when sharing-oriented output is requested. A private coaching report and
a shareable summary have different recipients. A request for a draft does not
publish it, send it or authorize uploading the underlying conversations.

For each proposed statement keep a small **private** claim map: claim ID, exact
bounded human contribution, supporting episodes/sources, uncertainty, intended
recipient/content scope and permission basis. This map and its private paths,
quotes, client names and transcript details are not part of the CV itself.

Choose keep/adapt/withhold/clarify with a reason:

- **Keep** supported behavior appropriate and authorized for the intended audience.
- **Adapt** to a truthful bounded role description using independently supported,
  permitted facts. Record limitations in the wording where material.
- **Withhold** unsupported, expressly restricted or unnecessarily identifying
  details; finish unaffected supported claims/private coaching.
- **Clarify** only the indispensable permission/evidence gap. Do not turn a useful
  private analysis into an unfinished questionnaire because one claim is uncertain.

Current authorization has actor, content, audience and action scope. Historical
approvals, model assertions, file relevance or possession of a transcript do not
authorize present sharing. Anonymizing a prohibited underlying fact does not
remove its restriction. A generic claim is usable only when its independent
support and current content/audience authorization allow it. Existing current
permission should be used without redundant approval questions.

Credit selection, adaptation, supervision and interpretation where observed.
Do not rewrite those as inventing the model's idea, writing its code, proving its
quality, leading an entire organization or becoming a senior expert. Avoid global
scores, percentiles, certificates, speculative field novelty and causal progress
claims. Not every feedback point belongs in a CV. Do not conceal material limits
that would make a chosen statement misleading.

Inspect the final shareable text itself: each factual clause supported; actual
role preserved; no private IDs/quotes/paths, distinctive restricted project facts,
third-party data or inflated outcomes. Name it a draft if not approved for the
specific destination. Say whether review was self-review or genuinely separate;
a second model alone is not certification. Keep evidence mapping private, and
revise/withdraw affected claims when corrected source evidence changes.
